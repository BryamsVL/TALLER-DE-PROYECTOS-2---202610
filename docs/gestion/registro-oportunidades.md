# 2º Registro de Oportunidades

**Proyecto:** SGOHA (Sistema de Generación Óptima de Horarios Académicos)  
**Mapeo Rúbrica:** 3.3.a.2º

La siguiente tabla registra los escenarios positivos y ventajas competitivas que el proyecto SGOHA puede capitalizar si se implementa y gestiona de manera exitosa.

| ID | Oportunidad | i. Impacto Positivo Esperado | ii. Estrategia de Aprovechamiento |
|---|---|---|---|
| **OP-01** | **Open Source Standard** | Medio | Publicar el código core de SGOHA como estándar abierto para UCs peruanas, atrayendo validación comunitaria y visibilidad académica. |
| **OP-02** | **Caché para Rendimiento** | Alto | Implementar TTL en memoria (Redis) para evitar recalculados innecesarios del motor CSP, bajando drásticamente el costo de procesamiento de servidor. |
| **OP-03** | **Portafolio Profesional**| Alto | Destacar el uso avanzado de FastAPI + CP-SAT como un diferenciador técnico extremadamente fuerte en el GitHub y portafolio del equipo. |
| **OP-04** | **Reutilización del Solver**| Alto | Parametrizar y abstraer las reglas de negocio para poder vender, exportar o ceder el módulo CSP a otras facultades y universidades. |
