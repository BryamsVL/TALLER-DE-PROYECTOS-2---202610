# SUS

## Instrumento

Aplicar el cuestionario SUS estandar con escala de 1 a 5:

1. Creo que me gustaria usar este sistema con frecuencia.
2. Encontre el sistema innecesariamente complejo.
3. El sistema me parecio facil de usar.
4. Creo que necesitaria apoyo tecnico para usar este sistema.
5. Las funciones del sistema estuvieron bien integradas.
6. Encontre demasiadas inconsistencias en el sistema.
7. Imagino que la mayoria de las personas aprenderia a usar este sistema rapidamente.
8. El sistema me parecio engorroso de usar.
9. Me senti seguro usando el sistema.
10. Necesite aprender muchas cosas antes de poder usar el sistema.

## Plan de aplicacion

- Participantes minimos recomendados: 5
- Perfiles sugeridos: 2 estudiantes, 2 docentes, 1 administrador/coordinador
- Escenario: login, navegacion al dashboard, tarea principal por rol y cierre de sesion

## Calculo

- Items impares: respuesta - 1
- Items pares: 5 - respuesta
- Sumar resultados y multiplicar por 2.5
- Objetivo: puntaje > 68
